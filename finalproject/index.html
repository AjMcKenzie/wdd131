Welcome to the Book of Mormon Recall Project

This website is designed to help you learn and remember the main doctrines and themes of each chapter in the Book of Mormon using a semi-mnemonic device.

How to Use This Website

To use this website, simply click on the "Learn" tab to learn the story that goes with each main doctrine and theme of each chapter. (Currently only 1 Nephi is available for this.)

You can also click on the "Chapters" tab to learn what each chapter number is represented by. For example, chapter 1 will always be represented by "Tie".

The "Books" tab to learn what each book of the Book of Mormon is represented by. For example, the book of "1 Nephi" will always be represented by "Nephi's Moving Van".

Finally, you can click on the "Test" tab to test your knowledge of the main doctrines and themes of each chapter in the Book of Mormon.
